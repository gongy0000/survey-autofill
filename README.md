# survey auto-fill (HEAL Form 1 / REDCap)

สคริปต์ช่วย "ติ๊กคำตอบไว้ก่อน" สำหรับแบบสอบถามออนไลน์ (REDCap survey)
โดยติ๊กคำตอบเชิงปฏิเสธ (ไม่ใช่ / ไม่มี / ไม่เคย ...) ให้ทุกคำถามที่เป็นปุ่มติ๊ก
ส่วนช่องที่ต้องพิมพ์เอง (ตัวเลข / วันที่ / ข้อความ) จะไม่ยุ่ง ปล่อยให้ผู้ใช้กรอกเอง

> ใช้เพื่อลดงานกรอกซ้ำ ๆ เท่านั้น — ผู้ใช้ต้องตรวจทานทุกข้อและกดส่งเอง

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้เมื่อ | ต้องลงอะไร |
|---|---|---|
| `survey_auto.py` | อยากกดรันใน VS Code (Run / F5) | Python + Google Chrome (สคริปต์ลง `selenium` ให้เอง) |
| `survey_tick_no.js` | เครื่องลง Python ไม่ได้ | แค่เบราว์เซอร์ — วางโค้ดใน Console (F12) |

ทั้งสองไฟล์ใช้ตรรกะเดียวกัน และมีตัวแปร `FORCE` / `EXCLUDE` ไว้กำหนดคำตอบเฉพาะข้อ

## วิธีใช้ `survey_auto.py`

1. ลง [Python](https://www.python.org/downloads/) (ตอนติดตั้งติ๊ก *Add Python to PATH*) และ Google Chrome
2. เปิด `survey_auto.py` ใน VS Code แล้วกดปุ่ม **Run** หรือ **F5**
3. ครั้งแรกจะติดตั้ง `selenium` ให้อัตโนมัติ
4. Chrome เปิดหน้าแบบสอบถาม แล้วติ๊กคำตอบให้ทั้งหน้า
5. ดูสรุปในหน้าต่าง **TERMINAL** (บอกว่าติ๊กกี่ข้อ / ข้อไหนต้องตอบเอง)
6. กรอกช่องที่ต้องพิมพ์ + ข้อที่ข้าม → ตรวจทาน → กดส่งในเว็บ
7. กลับมาที่ TERMINAL กด **Enter** เพื่อปิดเบราว์เซอร์

## วิธีใช้ `survey_tick_no.js`

1. เปิดหน้าแบบสอบถามในเบราว์เซอร์
2. กด **F12** → แท็บ **Console** (ถ้ามีเตือน ให้พิมพ์ `allow pasting` ก่อน)
3. คัดลอกโค้ดในไฟล์ทั้งหมด → วางใน Console → กด **Enter**
4. ตรวจทาน + กรอกช่องที่ต้องพิมพ์ → กดส่ง

## การปรับแต่ง

แก้ที่ส่วนบนของไฟล์:

- `FORCE` — กำหนดว่าข้อไหนให้เลือกคำตอบใด (ระบุ `ชื่อฟิลด์: "ข้อความตัวเลือก"`)
- `EXCLUDE` — รายชื่อฟิลด์ที่ไม่ต้องติ๊กอะไรเลย
- `SKIP_ALREADY_ANSWERED` — `True` = ไม่ทับข้อที่เลือกไว้แล้ว (รันซ้ำได้)
